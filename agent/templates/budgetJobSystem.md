Перед работой присвой задаче размер.

## S — малая

- 1–3 файла;
    
- известное решение;
    
- нет изменения архитектуры;
    
- нет миграции;
    
- нет публичных контрактов.
    

Настройка:

```text
Luna или Terra
Low
Один агент
Без plan mode
Targeted check
```

## M — средняя

- 3–10 файлов;
    
- один модуль;
    
- понятное поведение;
    
- могут потребоваться тесты.
    

Настройка:

```text
Terra
Medium
Короткий план
Один агент
Targeted tests + module checks
```

## L — большая

- несколько слоёв;
    
- backend и frontend;
    
- API или WebSocket contract;
    
- миграция;
    
- сложная авторизация.
    

Настройка:

```text
Sol
Medium или High
Сначала read-only research
Затем execution plan
Несколько вертикальных этапов
Отдельная review-сессия
```
