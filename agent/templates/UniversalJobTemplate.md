--- реальный пример 

## Цель

Добавить создание Hub и получение списка Hub текущего пользователя.

## Контекст

Существующий User используется для авторизации.
Room пока остаётся самостоятельной сущностью.
В будущем Space будет принадлежать Hub, но в этой задаче Space
не реализуется.

## Область изменений

Разрешено изменять:
- model/hub
- repository/hub
- service/hub
- controller/hub
- database migrations
- связанные тесты

## Ограничения

- Не изменять существующую работу Room.
- Не добавлять Space.
- Не возвращать JPA entities напрямую из controller.
- Проверять принадлежность пользователя.
- Не использовать EAGER для коллекций.
- Не создавать двунаправленные связи без необходимости.

## Критерии готовности

- Авторизованный пользователь может создать Hub.
- Создатель автоматически становится владельцем.
- Пользователь получает только доступные ему Hub.
- Чужой Hub недоступен.
- Ошибочные запросы имеют корректные HTTP-статусы.
- Добавлены тесты.

## Проверки

Запусти релевантные unit и integration tests.
Затем запусти полный backend test suite, если окружение позволяет.

## Формат работы

Сначала исследуй существующие patterns проекта и покажи короткий план.
После этого реализуй задачу.
В финале перечисли изменения, тесты и оставшиеся риски.
